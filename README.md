# Dignified Days AI Agent Prototype

A front-end prototype demonstrating an AI-assisted customer support workflow for durable medical equipment service scenarios.

## Overview

This project explores how an AI support agent could guide common customer-service interactions such as:

- Delivery status inquiries
- Equipment return scheduling
- Equipment malfunction triage
- Human escalation for urgent or complex cases

The prototype includes a simulated AI decision panel, confidence scores, action logs, escalation behavior, quick replies, and resolution metrics.

## Key Features

- Scenario-based customer support flows
- Interactive chat interface
- Simulated AI intent classification
- Confidence scoring and decision visualization
- Human-escalation logic
- Troubleshooting workflows
- Mock operational metrics
- Responsive single-page interface built with HTML, CSS, and JavaScript

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## What I Practiced

- Translating business workflows into an interactive prototype
- Designing AI-assisted customer support experiences
- Mapping customer intents to actions and escalation paths
- Building front-end state and interaction logic without a framework
- Thinking through human-in-the-loop AI workflows

## Important Note

This is a portfolio/demo prototype. All customer records, order numbers, delivery details, metrics, names, phone numbers, AI confidence values, and system actions are simulated. The project is not connected to Zendesk, an ERP, a production AI model, or live healthcare systems, and it does not make a production HIPAA-compliance claim.

## Run Locally

Download or clone the repository, then open `index.html` in a modern web browser.
